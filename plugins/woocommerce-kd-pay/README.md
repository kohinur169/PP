# KD Solution IT PayFac for WooCommerce

Official WooCommerce payment gateway integration plugin for KD Solution IT PayFac.

## Features
- Hosted & embedded secure checkout with zero PCI DSS CDE scope (SAQ A compliance).
- Instant multi-currency settlement (USD default).
- Automated webhook verification for instant order processing (`Processing` status transition).
- Complete Developer Sandbox and Test Mode toggle.

## Installation
1. Upload plugin zip `kd-solution-pay-woo.zip` in WordPress Admin -> Plugins -> Add New -> Upload Plugin.
2. Activate the plugin.
3. Go to WooCommerce -> Settings -> Payments -> KD Solution IT Pay.
4. Input your Merchant Publishable Key, Secret Key, and Webhook Signing Secret from your Merchant Dashboard.
5. Save settings.
